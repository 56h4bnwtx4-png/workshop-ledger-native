# 段誉的段 · iPadOS 原生版 v1.5.2

纯 SwiftUI 原生应用，不使用 WebView。账本保存在 iPad 应用沙盒内的 SQLite 数据库，正式账单、客户、员工、客户回款和工资发放记录会通过 HTTPS 自动备份到云端。草稿始终只保存在本机。

> TrollStore 升级时必须覆盖安装，不要先卸载旧版。卸载会删除本机 SQLite 数据库和钥匙串登录状态，升级前的自动备份也会随 App 沙盒一起丢失。

## v1.5.2 更新

- 打开已有正式账单后，日期锁定，不允许误改正式账单日期
- 已有正式账单没有未提交修改时，左下角显示“删除当日账单”，点击后必须二次确认
- 删除会同时删除该日账单明细和本机草稿，不可撤销
- 含已结清流水的账单禁止删除；需先撤销对应结清批次
- 已有正式账单存在未提交修改时，继续显示“放弃草稿”，不显示删除按钮
- 提交时对正式账单日期做硬校验，防止绕过界面改动日期

## v1.5.0 更新

- App 名称统一为“段誉的段”，Bundle ID 保持 `com.workshop.ledger.native` 不变
- 加工单价、员工工资单价、客户应收、员工应发、结款金额和差额全部支持三位小数
- 设置页拆分为客户管理、员工管理、客户回款、清账管理、工资发放、云端备份与恢复
- 客户可设置结算方式：按批结清或按年回款；产生首笔有效付款后结算方式锁定
- 客户应收 = 加工单价 × 数量 × 色数
- 员工应发 = 员工工资单价 × 数量 × 色数
- 同一客户所有型号共用一个加工单价，同一员工所有流水共用一个工资单价
- 第一次设置单价时，覆盖此前未保存单价的全部历史流水；之后修改只影响新流水
- 新增客户回款：按年记录到账，不绑定具体流水，不能超过截至回款日的未收加工费
- 新增工资发放：可按金额登记，允许预支或多发，只能整笔撤销
- 按批客户只使用清账批次，按年客户只使用客户回款，两种方式不会混算
- 报表改为年度统计：全厂年度结算、客户年度结算、员工年度结算
- CSV 继续使用 UTF-8 BOM，不包含提交时间；云端导出增加客户应收、员工应发和结清批次列
- 云端协议升级到 schemaVersion 3；旧 schema 1/2 快照可转换恢复，并按要求清除旧加工单价
- v1.5 数据库首次升级前会在 App 沙盒内自动生成一份 SQLite 备份

## 业务规则

- 色数只能选择 1、2、3、4、5
- 客户不能预存加工费；工资发放允许预支和多发
- 客户年度余额：正数表示客户尚未支付的加工费
- 员工年度余额：正数表示尚未发放，零表示已发清，负数表示预支或多发
- 清账批次和客户回款只能整笔撤销，原记录与撤销时间永久保留
- 已结清流水锁定，不能直接修改
- 同一账单日期合并恢复时，以所选云端版本为准

## 现有功能

- 固定横屏，仅支持 iPad / arm64，最低 iPadOS 15.0
- 全部账单：正式账单与本地草稿按日期倒序展示
- 计件录入：客户/员工整块触控下拉、型号联想、数量、1–5 色
- 新增一行时自动带入上一行客户和员工
- 草稿按日期自动保存，可放弃草稿
- 支持补录历史日期，也可直接修改已有账单
- 已有正式账单可安全删除（二次确认，已结清账单除外）
- 客户、员工档案独立管理，支持新增、编辑、查看和删除
- 原始流水、客户统计、员工统计、年度结算和 1–5 色分类统计
- CSV 导出：UTF-8 BOM，不包含提交时间
- 云端登录、自动同步、失败重试、从服务器数据恢复、最近快照恢复
- 云端快照每日 02:00 自动生成，保留最近 20 个成功快照
- 账号、密码和登录令牌保存在系统钥匙串

## 云端接口

默认服务器地址已固定在客户端：

```text
https://47-101-39-110.sslip.io
```

iPad 登录类型为 `ios`，拥有写入权限。Windows 登录类型为 `windows`，只能读取和导出。

服务器端接口：

- `POST /api/v1/auth/login`
- `GET /api/v1/workshop`
- `PUT /api/v1/workshop`
- `GET /api/v1/snapshots?limit=10`
- `GET /api/v1/snapshots/{id}/json`

v1.5.2 必须搭配服务端 v0.5.0（schema 3）。旧服务端会拒绝新金额字段、客户回款和工资发放数据。

## 私有型号词库

型号词库通过 GitHub Actions Secret `MODEL_CATALOG_B64` 在构建时注入，公开源码不包含实际型号清单。Secret 内容为 UTF-8 型号清单（一行一个型号）的 Base64。未设置 Secret 时仍可构建，但只会使用本机历史账单型号。

注入脚本会去空、去重，并限制最多 2000 条、单条最长 100 字符。词库文件仅打包进 App Bundle，不写数据库，也不参与云端同步。

## GitHub Actions 生成 IPA

1. 打开仓库的 **Actions** 页面，选择 **Build unsigned arm64 IPA**。
2. 点击 **Run workflow**。
3. 构建完成后下载 `WorkshopLedger-v1.5.2-iOS-arm64-unsigned` Artifact。
4. 解压后得到 `WorkshopLedger-v1.5.2-iOS-arm64-unsigned.ipa` 和 `SHA256SUMS.txt`。
5. 将 IPA 传到 iPad，使用 TrollStore 覆盖安装。

### 构建说明

- GitHub Actions 在 macOS 运行器上编译，产物是无签名 arm64 IPA，专供 TrollStore 安装
- Windows 环境只做源码、数据库迁移和服务端自动化测试，最终 iOS 编译状态以 Actions 为准
- 删除 App 会同时删除 SQLite 数据库和钥匙串登录状态
